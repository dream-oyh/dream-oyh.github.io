网站推荐

Edge 插件推荐

  • BewlyBewly: 因为侵权的原因，只能在 Chrome 上下载再安装到 Edge 上了。插件对 B 站页面进行了大调整，变得更美观了！
  • 首页插件
    • start.me：首页插件--便于对网页收藏夹的管理，支持导入 Edge 收藏夹，自定义化程度高，界面美观，但是完全依赖于 edge 浏览器缓存，删除 C 盘缓存后无法运行。不好用！恢复成青柠了
    • 青柠起始页：首页插件——极其简介，支持置顶便签，快速跳转站点捷径
  • uBlock Origin：网页广告屏蔽，自启动
  • 图片抓取助手：网页图片自动抓取
  • global video speed：网页视频倍速控制，最高支持 16 倍，支持对广告加速，但是优先级高于 B 站倍速控制，启用该拓展后 B 站倍速会失效
  • Dark Reader：暗色模式，支持调整对比度和棕褐色滤镜
  • elmo chat：支持对 B 站、Youtube 进行 AI 视频总结，方便记笔记
  • 魔法葫芦：支持对网页划线高亮，标注笔记，但是 UI 界面做的一般，免费
  • AI Code Finder：很好用的论文代码查找器，对于开源代码能直接读取出 github 仓库链接，科研人必备！
