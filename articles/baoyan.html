一些信息差

  1. 注意关注院校的强 com 和弱 com，com 指代学校委员会，强 com 指的是导师话语权没有效力，学校给了优营才算铁 offer，弱 com 指的是导师话语权很大，导师说要你就要你了
  2. 华中科技大学机械系是完全的弱 com，有同学在 3 月份就已经开始联系老师了，而且听说华科的机械老师方向都很好，比浙大好很多，建议有意向同学尽早联系
  3. 哈工深的夏令营和清华基本同一时间开始，注意查看通知，我在最后一天才听到消息，差点没报上；但是今年哈工深门槛很高，很难进，我们好像只有交控专业第一进了
  4. 一定一定要注意看学校官网发的通知，要注意以下几点：
    • 在系统提交完材料之后，有没有需要再在哪个系统或邮箱再提交一遍材料？（点名哈工大、同济汽车）
    • 如果夏令营没有入围，是否会通知，还是默拒，默拒有没有时间点
  5. 老生常谈的问题了，做一个 excel 表格整理好各个时间点，还有各个学校平台的账号密码，这个一定得记，很多学校是靠报名号登录的，账号特别容易混；而且各个学校密码要求不一样，有的要大写字母，有的又不要，建议报一个整理一个

导师评价

一些提醒

导师评价的收集是一个很隐晦、没法搬上台面、很零碎的收集过程，曾经的导师评价网风靡一时，但是最终也被公关处理。现在的导师评价都零零散散地散落在各大网站，只有通过多网址多方面的查询，才能获得对一位老师的完整评价，并且参考过程中务必注意以下几点：

  1. 不排除学生恶意评价老师的可能性。
  2. 有些老师会关注风评，即使对学生差，也强制要求课题组学生删除恶意评论，修改风评，请注意甄别
  3. 导师评价只是一小部分参考依据，保研、直博的导师选择涉及科研能力、师风师德、组内氛围、学生前途等多方位评价指标，请综合考虑再做选择。
  4. 导师也是人，会随着时间变化，注意评价的时间。
  • SAFC-Web 元平台、分布式——不只是评价导师

我现在在用的导师评价网，有 telegram 的频道，从 23 年 8 月创建，目前也一直在更新，我从另外一个知乎链接里找到了导师评价网里有关上海交通大学电子信息科学和工程学院的导师评价，并且通过 tg 贡献给了这个项目，不知道项目管理人员什么时候会集成进 web 端。

2024.7.28 浙江大学机械院夏令营——优营

需要 PPT，5min 展示

面经：

项目问题——问的很刁钻，基本把交科答辩时候的问题都问了一遍，老师眼很尖，一眼就能看出哪里可能会出现问题；

比如我们的 rPPG 心率恢复项目，老师第一个问的就是你们怎么处理光线变化问题

问了 YOLO 的原理，和怎么训练，怎么做训练集（这两个是我项目里有的东西）

专业课；（终于有老师问专业课了，没白复习，哭）

FAQ

  • 保研能否跨专业？

可以！我们交设专业主要对口就是机械方向，会偏自动化方向一点（但是上交还是建议报机动，别像我这么小丑）

  • 保研英语问题怎么准备？

    1. 要准备自我介绍，1 分钟、3 分钟两个时间段就够用了，然后一定要自己不看稿子过好几遍，形成肌肉记忆（这个很简单的，只要说出声来很快就能记下来，别怕）
    2. 准备一些简单的口语问题：hobby? hometown? sports? music? difference between our school and your school? 这些就差不多了
    3. 专业学术词汇，这个我没有遇到，但是我不知道其他学校有没有要考核翻译文献的，这个尽量大三期间多积累一些文献阅读量吧，日积月累的事情不太好速成惹
    4. 不用太为英语问题而紧张，一般来说老师不会太刁难人（至少我碰到的是），能说出东西来就可以了

  • 专业课怎么准备？

注重基础概念，可以参考我的浙大面经，问的问题都很基础，稍微过一遍就好

  • 如果面试有问题没答上来怎么办？

放轻松，别焦虑，只要你不是所有问题都不知道就好，你要知道别人的情况比你好不了多少（

  • 联系导师要联系小导师还是大导师？

都可以尝试联系，反正被拒了又不亏。但是注意不要同一所学校同时联系两个老师，被拒了以后再换。此外，如果有机会，大胆向老师提出加微信请求

  • 一般和老师聊要聊什么？

一类是老师自己会开话题，和你介绍课题组，这个不担心，跟着老师思路走就好；

另一类是老师沉默，等着你开话题，我这有几个话题供参考

  1. 老师您的课题组大方向是 xxx，我对此很感兴趣，但是想了解一下老师您课题组主要是做这个方向的哪一个部分呢？/主要在研究哪个应用场景？
  2. 老师您的课题组博士/硕士毕业要求是怎样的？（别怕，如果一个课题组不能明说毕业要求，那也劝你尽早润
  3. 老师您的课题组组会频率大概怎么样呀？
  4. 老师我觉得我的现有研究基础可能和您课题组的技术路线有点偏离，请问之后会有师兄带着我们补上相关基础吗？
  5. 老师您课题组的硕博连读制度是怎样的呀？（自己看，想读博就问问咯

具体问啥问题还是要看老师给你的回复以及想不想要你，大家自己把握叭~

大三这段时间，还能做啥？我做了啥？

还能做啥？

  • 竞赛 （已经有硬奖的可以跳过~） ——但是不要专注于奖项，而是专注于过程。竞赛最后的 title 会给你的简历增添亮点，但是最重要的还是个人能力的收获。
  • 科研——尝试发论文，这对保研很有用，但是前提是你自己深度参与的，而非挂名的。（真的不要一直想着挂名）

竞赛和科研是可以同时进行的。

我做了啥？

  • 交科赛——找了我想要做的深度学习方向和交通的融合项目，丰富了我自己的深度学习经历
  • 机器人视觉大赛——自觉交科赛不够，又在自院打了这个机器人视觉比赛，自己跑模型。很有趣的是，这个比赛最后我们十个人排第三，但是自院没有给我们奖。可是重要的是我对 YOLO 模型有了自己的理解，有了自己的经历，这才是最重要的~
  • 论文——在准备交科的同时深度参与了一篇综述论文的写作（感谢彭院能给这个机会！！），最后据浙大的师兄说，本科发论文很不容易，这也是你进来的加分项之一。
  • 科研技能——我想往编程方向转，这一学年学了 Python Github Git Latex C++ 数据结构与算法 等基本工具/技能的使用

大三这一年可以做很多事，如果也有想往计算机、深度学习方向转的同学欢迎交流~
