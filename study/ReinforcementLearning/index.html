  • state
    agent 在环境中的状态，RL 中最关键的一个量，需要根据实际情况自己确定。所有状态放在一起就是状态空间，S={si}\mathcal{S}=\{s_i\}S={si​}
  • action
    agent 在每一个状态都可能有一系列可能的行为，所有可能行为构成行为空间，A(si)={ai}\mathcal{A}(s_i)=\{a_i\}A(si​)={ai​}
  • state transition
    当 agent 做出一个 action 后，agent 的状态会发生改变，不同的 action 有不同的 state 转换，定义了 agent 和环境交互的行为。
    • 确定情况(deterministic)：可以直接用矩阵表达，维度是 S×A\mathcal{S}\times \mathcal{A}S×A
    • 随机情况(stochastic)：用条件概率表达： p(s2∣s1.a1)=0.2,p(si∣s1,a2)=0.8(∀i≠2)p(s_2|s_1. a_1)=0.2, p(s_i|s_1,a_2)=0.8(\forall i\ne 2)p(s2​∣s1​.a1​)=0.2,p(si​∣s1​,a2​)=0.8(∀i=2)
  • policy
    告诉 agent 每个状态下要采取哪个行动。π(a∣s)\pi(a|s)π(a∣s)
    • 确定情况：π(a2∣s1)=1,π(ai∣s1)=0(∀i≠2)\pi (a_2|s_1) = 1, \pi (a_i|s_1) = 0(\forall i\ne 2)π(a2​∣s1​)=1,π(ai​∣s1​)=0(∀i=2) 表示在s1s_1s1​状态下一定会采取a2a_2a2​的行动；
    • 随机情况：π(a1∣s1)=0.5,π(a2∣s1)=0.5,π(ai∣s1)=0(∀i≠1,2)\pi (a_1|s_1) = 0.5,\pi (a_2|s_1) = 0.5, \pi (a_i|s_1) = 0(\forall i\ne 1,2)π(a1​∣s1​)=0.5,π(a2​∣s1​)=0.5,π(ai​∣s1​)=0(∀i=1,2) 表示在s1s_1s1​状态下有对半开的概率采取 a1a_1a1​ 或 a2a_2a2​ 的行动；
  • reward
    agent 采取行动后，给 agent 的一个反馈值，如果是正值则代表鼓励这种行为，如果是负数就代表惩罚这种行为，如果是 0 就代表没有惩罚（一定程度上是鼓励）。通过 reward 告诉 agent 应该怎么做，不该怎么做。奖励取决于当前状态和行动，而不是下一步的状态。奖励集合：R(s,a)\mathcal{R}(s,a)R(s,a)
    • 确定情况：用 table 表示，行表示状态，列表示行动，值表示奖励值
    • 随机情况：p(r=−1∣s1,a1)=0.5,p(r=1∣s1,a1)=0.5p(r=-1|s_1,a_1)=0.5, p(r=1|s_1,a_1)=0.5p(r=−1∣s1​,a1​)=0.5,p(r=1∣s1​,a1​)=0.5,表示在 s1s_1s1​ 状态下采取 a1a_1a1​ 状态，有 0.5 的可能性拿到-1 的奖励，也有 0.5 的可能拿到 1.
  • trajectory
    状态-行动-奖励链。
  • return
    沿着某条轨迹得到奖励值总和。
  • discounted rate
    γ∈[0,1)\gamma \in [0,1)γ∈[0,1) 在达到目标之后，策略还在持续进行，会使得轨迹链变得无穷长，该轨迹的 return 也很大，所以要对每一步 policy 拿到的 reward 乘上一个折合因子（<1），使最后的 return 收敛。这样得到的 return 称作 discounted return.
    原来的 return：r1=0+0+0+1+1+1+⋯r_{1} = 0 + 0 + 0 + 1 + 1 + 1 + \cdotsr1​=0+0+0+1+1+1+⋯
    折合的 return：rdiscounted,1=0+γ×0+γ2×0+γ3×1+γ4×1+γ5×1+⋯r_{discounted,1} = 0 + \gamma \times 0 + \gamma^2 \times 0 + \gamma^3 \times 1 + \gamma^4 \times 1 + \gamma^5 \times 1 + \cdotsrdiscounted,1​=0+γ×0+γ2×0+γ3×1+γ4×1+γ5×1+⋯
    =γ3(1+γ+γ2+⋯ )=γ311−γ=\gamma^3 (1+\gamma + \gamma^2 + \cdots) = \gamma^3 \frac{1}{1-\gamma}=γ3(1+γ+γ2+⋯)=γ31−γ1​
  • episode
    agent 按照策略与环境交互时，到达终点时 agent 会停止，由此产生的轨迹被称为 episode。episode 一般是有限步的。
  • Markov Decision Process
    • 状态集合 S={si}\mathcal{S}=\{s_i\}S={si​}，行动集合 A(si)={ai}\mathcal{A}(s_i)=\{a_i\}A(si​)={ai​}，奖励集合R(s,a)\mathcal{R}(s,a)R(s,a)

non-incremental

之所以要提出蒙特卡洛，是因为在大多数情况下，我们是不知道系统模型的，无法使用贝尔曼公式。所以需要有大量的数据做支撑，来拟合出原有的数据分布概率模型。在蒙特卡洛方法里，旨在通过大量的尝试，推测出 qπk(s,a)q_{\pi_k}(s,a)qπk​​(s,a) 的期望值。然后再采用policy iteration做迭代优化。通过 vπ(s)=Σa(π(a∣s)qπ(s,a))v_\pi(s)=\Sigma_a (\pi(a|s)q_\pi(s,a))vπ​(s)=Σa​(π(a∣s)qπ​(s,a)) 计算下一步的 state value。

  • 最基础的蒙特卡洛算法：要求从一个随机估计的策略出发，对每一个(s,a)，都遍历N个episode，求这N个episode的平均return值作为(s,a)状态-策略对的action value。
  • MC-based Exploring Starts：遍历N个episode太过漫长，考虑任意一个episode链：(s1,a1)→(s3,a2)→(s2,a4)→(s2,a5)→⋯(s_1, a_1)\rightarrow (s_3, a_2)\rightarrow (s_2, a_4)\rightarrow (s_2, a_5)\rightarrow \cdots(s1​,a1​)→(s3​,a2​)→(s2​,a4​)→(s2​,a5​)→⋯ ，通过这个链，可以计算出 (s1,a1)(s_1, a_1)(s1​,a1​) 的action value，同时还能够获得 (s2,a4)(s_2, a_4)(s2​,a4​) 的action value，因为 g(s1,a1)=r(s1,a1)+γg(s3,a2)g_{(s_1,a_1)} = r_{(s_1,a_1)} + \gamma g_{(s_3, a_2)}g(s1​,a1​)​=r(s1​,a1​)​+γg(s3​,a2​)​。然后这个方法，就把这一次的episode作为action value的估计值，代入policy iteration做优化 （说是可以通过数学证明，证明出这样是依然收敛的，背结论吧，感觉后面多半不会用到）。
    • 在具体的编程实现中，建议逆序递推做累加，每一次都给return的值 +γg(st,at)+\gamma g_{(s_{t}, a_{t})}+γg(st​,at​)​ ，就能计算出这条链上每一个 (s,a)(s,a)(s,a) 的action value。
  • MC-based ε\varepsilonε-greedy：这里提出了soft policy的概念，也就是说每一个策略里每一个行动不是唯一确定的，而是有概率发生的，这个概率定义为：
    • 对于greedy action（就是action value最大的action），π(a∣s)=1−ε∣A(s)∣(A(s)−1)\pi(a|s)=1-\frac{\varepsilon}{|\mathcal{A}(s)|}(\mathcal{A}(s)-1)π(a∣s)=1−∣A(s)∣ε​(A(s)−1)
    • 对于其他action，π(a∣s)=ε∣A(s)∣\pi(a|s)=\frac{\varepsilon}{|\mathcal{A}(s)|}π(a∣s)=∣A(s)∣ε​
    • ε\varepsilonε 是[0,1]的一个正数，A(s)\mathcal{A}(s)A(s) 是当前状态所拥有行动的数目。
    • 之所以会选择用soft policy是为了平衡 exploitation 和 exploration，平衡探索性和最优性。

    ε\varepsilonε-greedy 其实就是把原来是确定性的 π(a∣s)\pi(a|s)π(a∣s) 转换成了stochastic的情况。
