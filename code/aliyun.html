阿里云服务器部署

学生认证领券入口

创建云服务 ECS 个人可以免费试用 3 个月，我的 wordbook 项目从 2025.2.14 开始配置在该免费试用的服务器上。

配置服务器参考教程：ref

  • 创建服务器后，可以配置密钥对，浏览器会返回一个.pem文件，这里面的内容是与服务器连接的 SSH 私钥

    服务器系统最好选择 linux 系统，如 Ubuntu20.04 版

  • 通过该 SSH 私钥可以在该云服务器上登录，进行远程连接

域名创建方法

  • 在阿里云网页上方搜索栏里搜索“域名”，完成阿里云实名认证 + 创建实名模板（需要上传身份证，需要一些时间审核）
  • 输入域名，按需选取，一般.xyz和.top的域名会比较便宜
  • 但是域名需要备案，备案却不可以选用按量计费ECS 阿里云你。。

宝塔面板安装（似乎没啥用）

  • 安装宝塔面板：在此处可以拿到安装命令，输入安装命令后，等待安装完成，注意要保存好云服务器的外网面板地址、内网面板地址、username 和 password，这会在安装完成后显示在命令行中，注意查看
  • 根据宝塔提供的端口号，在服务器的安全组里配置允许该端口访问。

    安全组在 ESC 面板的顶部可以找到，点击管理规则进入安全组规则配置

    选择手动添加，目的填端口号，源选择所有 IP，0.0.0.0/0

  • 将宝塔提供的外链地址在浏览器打开，输入初始用户名和密码（这就是刚才宝塔面板提供的那个账号密码），登陆后选择 LNMP 套件并安装

问题列表

  • 阿里云服务器自带内置防火墙，导致某些端口无法使用

关闭内置防火墙：sudo ufw disable，使用sudo ufw status可以查看防火墙状态，如果是Status: active则说明已启动，Status:inactive为关闭状态。

  • 安全组规则配置

一般对于保密级别不高的服务器（自己搭的也没有这个需要），可以把安全组的出入方向均设为全部允许

授权策略优先级协议类型端口范围授权对象
允许1全部源:-1/-1 目的:-1/-1所有 Ipv4(0.0.0.0/0)
