有关编程

本科在交通院，编程氛围只能说极其差了，甚至有人连 GitHub 是什么都不知道。编程基本是跟的 absx 学的，感谢他每个奇思妙想激励我一步步探索编程世界。2025.06 到浙大继续学习，发现这里的一切和本科相差甚远，大家对代码的理解比我深的多，但是基于本科的自学，我也能勉强和大家交流在一起，很开心，能学到很多新东西。

学习路径：

  • MATLAB：第一次懵懂地找老师进课题组，在师兄带领下做交通流的车流计数，摸爬滚打学会了 MATLAB，后面数模用了点，在接触 py 之前以为 matlab 特别好用
  • python：在 absx 的引导下学了 py，后续做深度学习也是用 py 做的，然后越来越发现 MATLAB 就是一坨……py 后面成为我的主力语言，大三大四两年都在用 py 写 code
  • C++：大一上了基本没啥用的 C++课，就放下了，直到夏令营准备数据结构，毕设做 ROS，浙大第一个项目做嵌入式开发，才慢慢重新捡起来
  • 嵌入式：项目所需，其次本来就有点兴趣，到浙大之后开始系统学
  • 前端（Vue 框架+TypeScript）：到浙大的第一个暑假，趁着周末时间慢慢学的，也是在 absx 激励下想学的

为什么喜欢

喜欢把想法落地变成实物的瞬间。前端的 ui，开发板的功能实现，都是满满的成就感。

代码编辑器

all in VSCode

抛弃 matlab 很大一部分原因也在于此，MATLAB 没法完全集成进 VSCode，其自带的 editor 的体验又尤其得糟糕。
