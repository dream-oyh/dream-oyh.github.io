无线充电

思路修正

  • 2025.8.4
    • 原本打算采用 CAN 转网络模块，利用 CAN 向初级继电器发送报文，但是 CAN 转网络模块的内置程序，并不支持解析 CAN 报文格式，会把 CAN 报文的帧信息（包括是否是远程帧/是否是扩展帧）和报文 ID 一起通过网络广播出去，初级继电器也没有解析 CAN 报文的能力，导致 CAN 报文发送了很多冗余数据，无法启动初级继电器。
    • 故之后考虑将 CAN 模块修改为串口通信，再用串口转网络模块控制初级继电器

stm32 参数与接口设置

  • APB1 总线时钟频率：32MHz

  • APB2 总线时钟频率：64MHz

  • CAN 时钟配置：

    • 采用时钟：APB1 总线时钟
    • 预分频器：16 分频
    • 时间段 1（BS1）：3TQ
    • 时间段 2（BS2）：4TQ
    • 波特率：250kbps

  • 次级 stm32 上引出了 USART2 引脚，定义：白色线为 PA3（RX），绿色线为 PA2（TX）

  • 串口资源分配

    • USART1(PA9, PA10): 转成 SRS232 通信
    • USART2(PA2, PA3): 用于控制初级继电器

stm32 控制程序

串口模块控制

  • 初始化程序
usart.c
UART_HandleTypeDef huart2;
// 初始化USART2
void MX_USART2_UART_Init(void)
{
  huart2.Instance = USART2;
  huart2.Init.BaudRate = 9600;
  huart2.Init.WordLength = UART_WORDLENGTH_8B;
  huart2.Init.StopBits = UART_STOPBITS_1;
  huart2.Init.Parity = UART_PARITY_NONE;
  huart2.Init.Mode = UART_MODE_TX_RX;
  huart2.Init.HwFlowCtl = UART_HWCONTROL_NONE;
  huart2.Init.OverSampling = UART_OVERSAMPLING_16;
  if (HAL_UART_Init(&huart2) != HAL_OK)
  {
    Error_Handler();
  }
}
// 配置两个HAL库中断函数
void HAL_UART_MspInit(UART_HandleTypeDef* uartHandle)
{

  GPIO_InitTypeDef GPIO_InitStruct = {0};
  if(uartHandle->Instance==USART2){

    __HAL_RCC_USART2_CLK_ENABLE();

    __HAL_RCC_GPIOA_CLK_ENABLE();
    /**USART1 GPIO Configuration
    PA2     ------> USART1_TX
    PA3     ------> USART1_RX
    */
    GPIO_InitStruct.Pin = GPIO_PIN_2;
    GPIO_InitStruct.Mode = GPIO_MODE_AF_PP;
    GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_HIGH;
    HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);

    GPIO_InitStruct.Pin = GPIO_PIN_3;
    GPIO_InitStruct.Mode = GPIO_MODE_INPUT;
    GPIO_InitStruct.Pull = GPIO_NOPULL;
    HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);
	}
}

void HAL_UART_MspDeInit(UART_HandleTypeDef* uartHandle)
{

  if(uartHandle->Instance==USART2){
	    __HAL_RCC_USART2_CLK_DISABLE();

    /**USART1 GPIO Configuration
    PA2     ------> USART2_TX
    PA3     ------> USART2_RX
    */
    HAL_GPIO_DeInit(GPIOA, GPIO_PIN_2|GPIO_PIN_3);

	}
}
  • 串口发送函数
    • fputc 函数重载了stdio.h标准库的输入输出流，可以让printf()打印函数，直接执行串口发送的功能。但是这样只能用一个串口了，不能指定用哪个串口进行发送
    • usart2_print 函数利用了 HAL 库的串口发送函数，可以指明用哪个串口资源发多长的数据，本项目采用第二种。
usart.c 重载输入输出流
int fputc(int ch,FILE *f)
{
	HAL_UART_Transmit(&huart2,(uint8_t *)&ch,1,HAL_MAX_DELAY);
	return ch;

}

  • 主函数调用：定义数据直接发送即可
main.c
uint8_t tx_startup_first_data[8] = {0X01,0X05,0X00,0X00,0xFF,0X00,0X8C,0X3A}; // 初级继电器启动
usart2_print(tx_startup_first_data,8);
  • 注意：
    • 程序在烧录完成后需要按下 stm32 开发板的复位按钮，才能执行新的程序，或者让 stm32 断电重启，一定要记得这一步，真是血与泪的教训
    • 串口转 USB 模块需要和 stm32 共地，否则数据传输会因为电磁干扰而失效，这也是实打实发生过的事，可能在可控环境下不接地也不影响，但是一旦电磁环境变得复杂，不接地就会出错
    • 本项目中外接 24V 电源为次级供电，通电前请注意电源是否连接开发板，如果让电源空载，但是两根电源线不小心碰一起短路会产生爆鸣和电火花……吓坏了 TvT
